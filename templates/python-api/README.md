# python-api

CLAUDE.md template for **Python FastAPI** projects.

Covers async API development with Pydantic v2, pytest, and ruff — opinionated conventions for production-grade APIs.

## What's included

- `CLAUDE.md` — Project conventions, patterns, and best practices
- `.claude/settings.json` — Recommended Claude Code permissions for Python projects

## Stack

- **FastAPI** — async web framework
- **Pydantic v2** — data validation and serialization
- **SQLAlchemy 2.x** (async) — ORM
- **pytest + pytest-asyncio** — testing
- **ruff** — linting and formatting
- **uv** — package management (preferred over pip)
