How it works

Three steps

No config. No setup. Just run the install command.

1

Pick a template

Run npx oh-my-claude list to see all available templates. Or preview <name> to read it before installing.

2

Install into your project

Run npx oh-my-claude install <name> in your project root. It drops CLAUDE.md and .claude/settings.json in place.

3

Open Claude Code

Claude Code automatically reads CLAUDE.md on startup. Your agent now knows your stack, conventions, and patterns.
